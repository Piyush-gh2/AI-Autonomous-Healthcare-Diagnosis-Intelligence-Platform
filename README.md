# 🏥 AI Autonomous Healthcare Diagnosis Intelligence Platform

## 🚀 Overview

An AI-powered healthcare intelligence platform that predicts disease risks, analyzes patient vitals, and generates explainable clinical insights using predictive analytics, RAG, and multi-agent architecture.

---

## 💡 Features

- Disease risk forecasting
- Clinical anomaly detection
- Explainable AI insights
- RAG-powered medical intelligence
- Multi-agent coordination
- Streamlit dashboard

---

## ▶️ Installation

pip install -r requirements.txt

---

## ▶️ Run Project

streamlit run app.py
